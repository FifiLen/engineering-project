# Aplikacja mobilna

React Native z Expo (ADR 0005). Uruchomienie z katalogu głównego repozytorium:

```bash
pnpm --filter @hulajnogi/mobile dev
```

Zależności Expo instaluj poleceniem `pnpm --filter @hulajnogi/mobile exec expo install <pakiet>`, które dobiera wersje zgodne z SDK. Wskazówki dla asystentów AI: `AGENTS.md` (z szablonu Expo).
