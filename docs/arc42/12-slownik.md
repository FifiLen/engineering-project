# 12. Słownik

| Pojęcie | Znaczenie |
|---|---|
| Przejazd | Jedno wypożyczenie hulajnogi, od rezerwacji lub odblokowania do zakończenia |
| Strefa parkowania | Obszar, w którym można zakończyć przejazd |
| Strefa wolnej jazdy | Obszar z obniżonym limitem prędkości |
| Strefa zakazu | Obszar, w którym jazda i parkowanie są wyłączone |
| Obszar działania | Granica usługi |
| Komenda | Polecenie z backendu do hulajnogi (np. `unlock`), z identyfikatorem `commandId` |
| Potwierdzenie (ack) | Odpowiedź hulajnogi na komendę |
| Telemetria | Okresowy raport hulajnogi: pozycja, bateria, prędkość |
| Last Will | Wiadomość, którą broker MQTT publikuje w imieniu klienta po zerwaniu połączenia |
| Księga portfela | Lista wszystkich ruchów środków; saldo jest jej sumą |
| Idempotencja | Własność operacji, której powtórzenie nie zmienia wyniku |
| Dyspozytor | Pracownik operatora monitorujący flotę |
